# 🎁 Nomadic Scout – Diwali Gifting Website

A festive gifting website concept created as my **first website practice project** using Lovable AI and AI-assisted prompt creation.
- **Website:** [Nomadic Scout](https://lovable.dev/preview/CjEfUP3pDejnLq2hMOGLG4DUMbE2fldb)

## 🌟 About the Project

Nomadic Scout is a conceptual Diwali gifting store designed with a modern Gen Z aesthetic. The idea was to explore creative hamper collections, attractive product displays and a simple, user-friendly shopping experience.

The website features three main gifting categories:

- **Kids:** Six themed hamper concepts inspired by Marvel, Ben 10, Anime, Barbie, DC and more.
- **For You:** Individual hampers featuring dry fruits, snacks and mixed combinations.
- **Family:** Gifting concepts for families of 2, 4 and 6 people.

## ✨ Key Features

- Festive homepage and brand identity.
- Creative product and category displays.
- Conceptual product descriptions and pricing.
- Colourful visuals and festive decorations.
- About and FAQ sections.
- Instagram links for product enquiries.
- Responsive layouts and interactive elements.

## 🎨 Design

Inspired by **Gen Z Pop Festive and Dreamy Diwali**, featuring:
- Coral, pink, peach, lilac and warm cream colours.
- Festive illustrations and decorative elements.
- Attractive product imagery.
- Smooth transitions and interactive design.

## 🛠️ Tools Used

- **AI Tools:** Brainstorming ideas and assisting with prompt writing.
- **Lovable AI:** Website creation and design.
- **Prompt Engineering:** Structuring and refining website requirements.

- Turning an idea into a website concept.
- Using AI to develop and refine prompts.
